# Flutter app

This folder contains the Android-first Flutter application for the Digital Filipino Storybook Platform.

## Stack

- Flutter
- Dart
- Provider
- GoRouter
- Dio
- SharedPreferences
- Material 3

## Local setup

1. Install Flutter SDK.
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```

## Core screens

- Story catalog
- Story detail
- Reader experience
- Parent dashboard
- Admin dashboard

## Notes

The app is designed to be mobile-first and compatible with future web/iOS expansion, while keeping the product experience tailored to Filipino children’s literacy and storytelling.
